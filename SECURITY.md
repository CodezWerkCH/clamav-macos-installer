# Security reporting

Do not publish credentials, malware/quarantine contents or personal scan logs in a public issue. For a vulnerability, contact the maintainer privately through the contact options on the GitHub profile before sharing a reproduction publicly. Do not attach real malicious files.

This project is a scheduled scanner installer, not a guarantee of protection. Please include the app version, macOS version, affected component and a harmless minimal reproduction. The repository contains no signing credentials, personal logs or installed virus databases.
